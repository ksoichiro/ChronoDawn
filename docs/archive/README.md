# Historical designs and research

These documents preserve earlier design decisions, investigations, and ideas.
They are snapshots, not authoritative descriptions of the current release.
Some roadmaps and proposals contain work that was not implemented when they
were written. Check the current guides, configuration, and source before using
any details or starting work from them.

- [Original Chrono Dawn designs and research](chrono-dawn-mod/): gameplay
  philosophy, lore, data model, visual concepts, and future ideas.
- [Dated designs and roadmaps](superpowers/): decisions behind individual
  features and longer-term proposals. The dated implementation plans were
  removed after their work was incorporated into the project.
- [Initial design](initial_design.md) and [compatibility-layer design](compat_layer_design.md).
- [Implementation history](implementation_history.md) and [portal implementation plan](portal_implementation_plan.md): historical technical context.

For current information, start with the [player guide](../player_guide.md),
[developer guide](../developer_guide.md), and [configuration guide](../configuration.md).
